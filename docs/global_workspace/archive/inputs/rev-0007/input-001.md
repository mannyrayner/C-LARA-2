For both these reasons, I think we should post updated versions of the papers now on ResearchGate as insurance, keeping the original author lists but adding two significant developments that have occurred over the last couple of weeks:



1. With Sarah's consent, I have uploaded the session summaries to the repo. I just checked, and I can indeed get answers to questions about them using the Assistant. 



2. Recent improvements to ChatGPT mean that we can now effect a much cleaner preliminary integration of Voice Mode and C-LARA-2 than the very ugly one we describe in §5. It's now possible to open two browser windows as before, one for ChatGPT and one for C-LARA-2, and, as before, open a text in the C-LARA-2 window. But now, an important practical difference, we can just pass the URL of the C-LARA-2 text to ChatGPT before switching to Voice Mode. ChatGPT can then access the text directly, navigate between pages, and view images, so this is already more or less usable. Of course, further improvements would still be welcome.
