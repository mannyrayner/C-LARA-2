I am starting this dedicated thread to work on the idea we've already discussed several times: a lightweight language-learning app, organised with interactive community-based construction of picture/audio dictionaries in the centre, and designed from the start to work well on mobile devices. When we started talking about this, we were saying it should be for Indigenous languages, but on reconsideration I'm wondering if it wouldn't be better to generalise and allow it to be used with AI-supported languages as well. One obvious plus is that I would then be able to test it myself: I don't know any Indigenous languages, except a very small amount of Pitjantjatjara.

One specific thing I am interested in exploring is to find out if you (high-end versions of Astra) can build most or all of the app in a few shots. I have seen how quickly you can construct large chunks of good software, and as long as we are moderate in our ambitions this doesn't seem impossible. We don't want it to be too fancy, that may well be counterproductive. Supporting a few simple core functionalities well may produce something much more useful. If it turns out that you can do it, people in the CALL world may well find that interesting. I don't think most of them know how quickly the models are improving.

If this makes sense, maybe we could start by putting together an initial spec?
