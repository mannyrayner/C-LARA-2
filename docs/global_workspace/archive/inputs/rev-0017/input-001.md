Thinking further ahead, in particular about how I would in practice like to use this app to improve currently very poor spoken Italian, here are some ideas which I don't think should be too hard to implement:

1. I'd like to have spoken sentences included as well as words, while keeping to the basic principle of grounding as much as possible in visual experience.
2. There are several ways we could do this. A minimal way, which would work for Indigenous languages with no AI support, would be for the language-capable partner to record a sentence about the image as well as the word. So for example with Cathy's teapot image, I just recorded the Swedish word "tekanna". But I could also have added the sentence "Tekannan står på bordet", optionally with a translation.
3. If an AI is available, it can construct the sentences and also the audio for the sentences. 
4. It can moreover try to adapt the sentences to a particular learner's history, by as far as possible reusing words the learner has already entered. It can also annotate the sentences, reusing C-LARA-2 functionality, so that words in them link to the earlier entries when possible.

My intuition is that I'd find this strongly reinforcing, since my learning would as far as possible be grounded in my own real-world experience, and I'd constantly be referred back to earlier learning episodes. We'd probably want to play around with the interface a bit to find good modes for doing this; for example, you maybe don't want to click on words to see the images, but rather have an option that automatically scrolls the whole sentence together with the words. I am no expert on language pedagogy, but what I do know it suggests that this agrees well with mainstream theories. We also have people in the C-LARA group who are very interested in language pedagogy, picture books and picture dictionaries.
