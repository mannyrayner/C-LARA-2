This sounds like a very interesting direction to explore. We should talk more about it.

Before we do that, though, here's a much simpler idea which we should probably add for AI-supported languages. At the moment, we can use the camera to add images that will be included in dictionary entries. But surely it would make sense to broaden this, so that learners could first capture an image, then ask for language feedback? If it's clear that the image is intended to represent a single object, it could just speak/show the name of the object; if it's a small number of objects, it could give all of them, perhaps with a sentence saying how they are related. One or two of the apps you named have related functionalities, they are obviously going to be very useful. Here, we would presumably both capture the image and give the user the option of adding it to the community dictionary.

An immediate question: roughly how expensive would it be to carry out the requisite image understanding?

Ideally, one would like to extend the idea to video, though I imagine that's substantially harder and would be best left to a later step. Second question: how feasible do you think it is?
