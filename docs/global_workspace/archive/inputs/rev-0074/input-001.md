This is great, I think we're now close to the point where we could consider posting it. Some more comments:

1. We should make it clear that we started by creating the Swedish dictionary, and then automatically created the versions for the other languages by adding functionality at a later stage to supported automatic language conversion, and which uses AI-based translation and TTS-generated audio. We should in particular note that AI-based translation uses both text and images as input.
2. We should also note that the French examples in the figures come from the automatically converted French dictionary, and that the AI-generated language is arguably not completely correct: the AI has looked at the piece of furniture the cat is lying on and decided to use the words "fauteuil" in French and "armchair" in English. This is an interesting example of how hard the problem is! I would say "armchair" was wrong; I am not sure about the French, but am inclined to say it's right. But most people would say "armchair" was a normal English translation of "fauteuil".
3. §4, "The paper should evolve with the app". I think it's closer to the truth to say that we aim to produce a rapid sequence of papers tracking the project's progress. This is the first one; we hope the second will contain some empirical data.
4. "Kowanyama, Kanak-language communities". I think it is inappropriate for us to name specific communities here, since neither of the authors represent any of them. We could refer to them indirectly by citing this paper: [https://www.researchgate.net/publication/389545354_Building_culturally_relevant_multimedia_resources_for_Indigenous_languages_using_AI_tools_and_collaborative_development_extended_abstract](https://www.researchgate.net/publication/389545354_Building_culturally_relevant_multimedia_resources_for_Indigenous_languages_using_AI_tools_and_collaborative_development_extended_abstract)
