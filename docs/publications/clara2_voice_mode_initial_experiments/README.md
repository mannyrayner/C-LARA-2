# Combining C-LARA-2 and ChatGPT Voice Mode: Initial experiments

This directory contains the first repository version of a new report based on
and extending the EuroCALL 2026 submission **Using ChatGPT Voice for spoken
German practice: A case study**.

The EuroCALL submission remains unchanged in
[`../eurocall_2026_voice_mode/`](../eurocall_2026_voice_mode/). This report is a
separate publication artifact, not a replacement submission. It retains the
same author list and adds an initial investigation of combining ChatGPT Voice
Mode with C-LARA-2.

## Contents

- [`latex/clara2_voice_mode_initial_experiments.tex`](latex/clara2_voice_mode_initial_experiments.tex)
  is the report source.
- [`latex/references.bib`](latex/references.bib) is copied from the EuroCALL
  manuscript so this report can be built independently.
- The supporting session records remain in the original study's
  [`session_summaries/`](../eurocall_2026_voice_mode/session_summaries/)
  directory; they are linked rather than duplicated.

## Main changes from the EuroCALL paper

- Reframes the work as a pre-study for adding free spoken conversation to
  C-LARA-2.
- Separates two questions: the quality of Voice Mode as a free conversation
  partner and the practicality of integrating it with C-LARA-2.
- Replaces the earlier screenshot-based integration discussion with the newer
  URL-based two-window workflow.
- Adds a repository-grounded Assistant example using the consented session
  summaries, while retaining the warning that they are retrospective records,
  not transcripts.
- Adds a first-page provenance note explaining the relationship to the
  unresolved EuroCALL submission and linking to its preserved source.

## Revision notes

- The first revision after the initial draft adds the rationale for selecting
  ChatGPT Voice Mode / Pro Tier, mentions Jumpspeak as a commercial comparison,
  normalises the system name, and time-bounds the pedagogical-control findings
  in light of a later informal ChatGPT version 5.6 test.
