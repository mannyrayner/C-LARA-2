# EuroCALL 2026 C-LARA-2 autonomy paper (LaTeX conversion)

This directory contains a repository-oriented LaTeX conversion of the final
Word manuscript supplied inline on 1 August 2026.

- Main source: `eurocall_clara2_v6e.tex`
- Figure descriptions: `figures/README.md` (the submitted JPEGs are intentionally represented as text for PR compatibility).
- Bibliography: `references.bib`.
- The provisional proceedings citation still contains editor-name and DOI
  placeholders, so it is not presented as a final citation in the LaTeX source.
- The numbered footnote markers visible in the pasted Word text did not include
  their footnote bodies. They are therefore omitted rather than reconstructed
  speculatively.
- The source uses labelled placeholders for the four submitted figures; the six
  constituent screenshot descriptions remain in `figures/README.md` until the
  binary images are supplied separately.
- The known chronology correction is retained: C-LARA development began shortly
  after GPT-4 was released in March 2023.
