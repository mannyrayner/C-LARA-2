# Session summaries

This directory contains the post-session summaries associated with **Using
ChatGPT Voice for spoken German practice: A case study**. They are included so
that maintainers and the repository-grounded C-LARA-2 Assistant can examine the
evidence behind the paper and explain how individual sessions relate to its
findings.

## Provenance and permission

- ChatGPT generated the detailed written summaries for Sessions 1–3 and 6–8; the paper
  identifies AI-generated post-session summaries as the study's main dataset.
  Session 4 is represented by contemporaneous notes written by Manny Rayner.
- Sarah Wright approved uploading the session summaries to this public
  repository. Manny Rayner reported that approval on 10 August 2026.
- The first summary was supplied to the repository task on 10 August 2026 as
  pasted text after attempts to attach the current `.docx` source were
  unsuccessful.
- The Markdown conversion regularises headings, lists, punctuation, and tables
  for readability. It does not intentionally add observations or strengthen
  the source's research claims.
- These documents are retrospective session records, not recordings or formal
  transcripts. Their authorship is recorded in each file's metadata.
  Approximate durations and interpretations remain those of the source record
  unless explicitly identified otherwise.
