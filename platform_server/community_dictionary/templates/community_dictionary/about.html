{% translate "Your language, your choices" %}

{% translate "Human pictures, text and recordings work without AI support for the language. Where suitable AI support is available, you can optionally ask for picture descriptions, translations, speech or generated illustrations. An owner can add missing sentences to a collection of pictures, then build vocabulary from the reviewed sentences." %}

{% translate "AI suggestions can be wrong and should be checked by someone who knows the language. Optional AI processing can spend credits and send selected material to a provider; the relevant tools explain their processing and costs. It is not required for manual dictionary work." %}

{% translate "Members, and visitors to dictionaries with public browsing enabled, can practise with flashcards, picture crosswords and word-search puzzles using the dictionary's existing material. These exercises make no paid AI calls." %}

{% translate "Decide what to share" %}

{% blocktranslate %}Dictionaries start private and unlisted. Owners can make a dictionary discoverable, showing its name, languages and accepted entry counts so people can request membership. This does not expose its contents.{% endblocktranslate %}

{% blocktranslate %}Public browsing is a separate owner choice, made with contributor permission. It allows anyone with the link to browse accepted learning material. A public dictionary only appears in the discovery list if it is also discoverable.{% endblocktranslate %}

{% translate "Contributors can withdraw all their contributions from a dictionary into their private collection and later restore them. Withdrawal blocks subsequent access to the hosted material, but cannot recall copies people already received. Hidden dictionaries are not advertised. Your personal contributor listing is optional too." %}

{% translate "A project that learns from its users" %}

{% translate "Community Dictionaries is part of the open-source C-LARA project. AI has written the application code and technical documentation through an iterative collaboration with people who propose requirements, install releases, test them and give feedback. The aim is to make useful changes quickly while keeping the app understandable." %}

{% translate "The project is still developing. We are investigating how well this approach serves different language communities, and how much technical work AI can reliably take on over time. Independent community trials and long-term results are still needed." %}
