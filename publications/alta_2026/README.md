# ALTA 2026

Working material for a possible submission to ALTA 2026, Melbourne, 29 November
to 2 December 2026. The submission scope and author list are not yet fixed.

## Team updates

- [7 August 2026: preliminary GPT-5.6 prompt-learning results](team_updates/2026-08-07-preliminary-results.md)

## Current status

The work is preliminary: a small English development set has been manually
reviewed for `segmentation_phase_2` and MWE annotation, but there is not yet an
evaluation on unseen data. French and German are likely candidates for the
multilingual evaluation once the English protocol and MWE annotation policy are
stable.
